# Sindy Jwili — Data Analyst Portfolio

Four projects built on one real dataset (149,116 point-of-sale
transactions from a 3-location coffee shop chain), each proving a
different skill at increasing technical depth.

**Live site:** `https://sindy290.github.io/sindy290-data-portfolio/`
(after enabling GitHub Pages — see below)

## Projects

| # | Project | Skills | Folder |
|---|---|---|---|
| 1 | Excel Sales Analysis | Excel, pivot tables, formula-driven analysis | [`project-1-excel-analysis/`](./project-1-excel-analysis) |
| 2 | SQL + Python Analysis | Relational database design, SQL (joins, CTEs, window functions), Python | [`project-2-sql-python/`](./project-2-sql-python) |
| 3 | Interactive Dashboard | HTML/CSS/JS, Chart.js, data visualization | [`project-3-dashboard/`](./project-3-dashboard) — [live demo](./project-3-dashboard/index.html) |
| 4 | Business Case Study | Business writing, evidence-based recommendations | [`project-4-case-study/`](./project-4-case-study) |

Each folder has its own README with details, key findings, and how to
reproduce the work.

## Why one dataset, four projects
Rather than four disconnected tutorial exercises, this portfolio
analyzes the same business with increasing depth — a spreadsheet, then
a proper database, then an interactive tool, then a written
recommendation. That progression is the point: it shows the same
findings held up under different tools and a consistent line of
business judgment, not just familiarity with software.

## How to publish this as a live site
1. Push this folder to a GitHub repository (e.g. `sindy290-data-portfolio`).
2. Go to the repo's **Settings → Pages**.
3. Under "Build and deployment", set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your site will be live at `https://sindy290.github.io/<repo-name>/` within a few minutes.

## Before publishing
- Edit the "About" paragraph in `index.html` with a couple of real
  sentences about your background and what you're looking for.
- Replace the placeholder email link in the footer of `index.html`
  with your real contact info (or remove it).

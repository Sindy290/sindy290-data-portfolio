# Project 4 — Business Case Study

A written business case study that ties together the findings from
Projects 1–3 into a single decision-oriented recommendation document —
the kind of deliverable a data analyst would actually hand to a
non-technical stakeholder.

**File:** `Coffee_Shop_Business_Case_Study.docx`

## What's inside
- **Executive summary** — the recommendation stated up front.
- **Business question, data & methodology, and stated limitations.**
- **Analysis** across 6 findings: store balance, morning-peak demand concentration, monthly growth trend, store-level menu differences, and a pricing data-quality issue.
- **A ranked recommendations table**, each row tied to specific evidence and a confidence level — no recommendation is made without a number behind it.
- **A "What This Data Cannot Answer" section** — explicitly declines to recommend a 4th store location, since that would require real-estate and market data this dataset doesn't contain.

## Why this project matters in the portfolio
Projects 1–3 prove tool skill (Excel, SQL/Python, dashboards). This
project proves judgment: turning numbers into a recommendation a
business could actually act on, while being explicit about what the
data can and can't support.

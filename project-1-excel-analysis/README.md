# Project 1 — Excel Sales Analysis

A pivot-table-driven analysis of 149,116 coffee shop transactions across
3 NYC locations (Jan–Jun 2023), built entirely with formulas — no
hardcoded values.

**File:** `Coffee Shop Sales Analysis.xlsx`

## What's inside
- **Executive Summary tab** — the business question, key findings, and recommendations, written for a non-technical reader.
- **Summary tab** — pivot-style tables (all live `SUMIFS`/`COUNTIFS` formulas) plus 5 charts: revenue by store, monthly trend, revenue by category, revenue by weekday, revenue by hour.
- **Raw Data tab** — the full transaction log with derived columns (revenue, hour, weekday, month).

## Key findings
- Store performance is balanced (32.9%–33.9% split across 3 locations).
- Revenue more than doubled from February to June.
- Coffee + Tea drive ~67% of all revenue.
- 8–10am generates 36.7% of daily revenue — the clearest staffing signal in the data.
